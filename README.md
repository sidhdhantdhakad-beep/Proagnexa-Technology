# Proagnexa Technology

Comprehensive Technology Solutions for Your Business. Modern web platform featuring dedicated Homepage, Services with interactive filtering, About Us, and responsive design.

## Tech Stack
- **Framework**: React (Vite)
- **Styling**: Vanilla CSS & Modern Component Architecture
- **Icons & Assets**: Custom SVG & High-resolution Tech Graphics

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
